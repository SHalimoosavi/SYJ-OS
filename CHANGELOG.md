# Changelog

## 0.1.0 — 2026-10-15

Initial SYJ OS Virtual Device prototype.

- Virtual smartphone shell with responsive device profiles.
- Boot, lock, home, app drawer and system navigation surfaces.
- Virtual hardware state and local persistence.
- Settings and Calculator proof apps.
- Theme, wallpaper, security, battery and network controls.
- PWA manifest, service worker and GitHub Pages workflow.
- Vitest and Playwright test foundations.
